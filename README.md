# 🎬 AI 영상 스튜디오

AI 홍보영상 제작사업(목표 월 1,000만 원)의 업무 자동화 프로그램입니다.
영업비서 앱(`ai-assistant` 저장소)과 완전히 따로 있는 저장소입니다. 데이터 저장 공간도 따로 씁니다.

## 할 수 있는 일

왼쪽 메뉴(휴대폰은 ☰ 메뉴)에 영상 만들기 · 사업 관리 · 도구가 묶여 있습니다. 안 쓰게 된 기능은 앱에서 끄지 않고 프로그램에서 아예 삭제합니다 (기능마다 코드가 `/* ---------- … ---------- */` 묶음으로 나뉘어 있음).

|---|---|

## 🤖 AI 연결 (구글 Gemini API)
- ⚙️ 설정 → **AI 연결**에 구글 API 키(aistudio.google.com에서 발급)를 넣습니다. 키는 이 기기에만 저장되고 백업 파일에 들어가지 않습니다.
- 그림·목소리·영상은 구글 **결제(유료 등급)**를 켜야 쓸 수 있습니다.
- 쓰는 모델 (2026-11 기준, 설정 → 고급에서 바꿀 수 있음): 그림 `gemini-nano-banana-2.1`, 목소리 `gemini-3.8-flash-lite-tts`, 고급 영상 `gemini-omni-1.2-flash`
- 예상 비용 (구글 요금표 2026-11): 그림 1장 약 $0.034, 목소리 10초 약 $0.0015, 영상(720p) 1초 약 $0.07 → 그림 1장 약 70원, 영상 30초 약 3천 원
- 스튜디오 합치기·루프 영상은 브라우저 안에서 영상 길이만큼 걸립니다. 그동안 화면을 끄지 마세요.

## 자동화 방식
- 외부 AI로 정보를 보내지 않습니다. 업종별 문구 틀과 장면 자료로 앱 안에서 바로 만들기 때문에 **무료**입니다.
- 더 다양한 결과가 필요하면 **🤖 AI에게 보낼 프롬프트 복사**를 눌러 Claude·ChatGPT에 붙여넣습니다.
- 나레이션은 1초에 6글자를 기준으로 길이를 확인합니다.
- 업종별 문구 틀은 `index.html`의 `IND`(업종 자료), `STRENGTH_SHOTS`(강점 → 장면), `MOODS`(분위기)에서 고칩니다.
